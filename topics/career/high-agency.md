# High agency

Agency is the ability to act and influence what happens. At work, high agency means looking for a useful next action when a goal is blocked or the instructions are incomplete.

This can be as small as identifying the missing decision, contacting the right owner, or testing an assumption.

## Separate the goal from the current obstacle

Suppose a migration is waiting for an API owned by another team.

The dependency is real. The next question is what can still move forward:

- Confirm what the API must provide.
- Ask the owner for a delivery estimate.
- Test the integration against a small stub.
- Identify which parts of the migration depend on the API.
- Escalate the scheduling conflict with its impact and possible choices.

```text
Goal: migrate the service
            |
Blocker: external API unavailable
            |
    +-------+--------+--------+
    |                |        |
clarify contract   test stub  agree timeline
```

The blocker limits the available actions, but it may not stop every useful action.

## Take responsibility for follow-through

Finishing an assigned piece does not always finish the outcome. A change may still need review, rollout, or confirmation that it solves the original problem.

Follow-through includes:

- Making the next owner clear.
- Checking that a handoff was received.
- Reporting unresolved risks.
- Confirming the result after the change.

It does not mean silently taking every task onto one person. Clear coordination often achieves more than individual rescue work.

## Work within real boundaries

Some decisions need authorization. Some constraints cannot be removed by effort. High agency includes recognizing those limits and making them visible.

For example:

> The migration cannot meet Friday's date unless the API arrives by Wednesday. The choices are to reduce scope, move the date, or assign help to the API team.

This gives decision-makers something they can act on.

## Build the habit through small actions

Start with actions that reduce uncertainty or unblock others:

- Ask the uncomfortable but necessary question.
- Propose a small experiment.
- Bring options with a problem.
- Follow up on an unanswered request.

Useful initiative connects action to the goal. It also respects ownership, capacity, and the people affected by the decision.
