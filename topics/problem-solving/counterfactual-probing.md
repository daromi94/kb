# Counterfactual probing

Test a claim by changing the surrounding conditions. Remove an
element, exaggerate a quantity, or invert a constraint — then check
whether the original conclusion still holds. Flaws hidden under
normal conditions become visible at the extremes.

## How it works

A claim that holds under current conditions may rest on a hidden
assumption that disappears when those conditions shift. Pushing a
variable to its limit forces the critical assumption into view. If
the claim survives the change, it is grounded in something real. If
it collapses, the reasoning was leaning on a condition that was
never stated.

## Application questions

- If a key resource were absent, how would the approach change?
- If the suspected cause were removed, what would fail first?
- If the scale doubled, would the underlying problem still exist?
- If a simpler partial fix already addressed most of the issue,
  would the larger one still be justified?
