# Heuristic questions

Mental operations that trigger progress when you are stuck in the
planning phase.

## Analogy

Can you find a simpler analogous problem? Solving an easier version
of the same structure often reveals the method for the harder one.

## Decomposition and recombination

Can you break the problem into parts? Can you rearrange those parts
into a more tractable form? Separating a problem into independent
sub-problems reduces each one's difficulty.

## Auxiliary elements

Can you introduce a new element — a helper line in geometry, an
intermediate variable, an additional constraint — that makes the
solution easier to see? The element does not change the problem; it
changes your view of it.
